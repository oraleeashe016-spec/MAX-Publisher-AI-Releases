# MAX Publisher AI — публичные обновления

Этот репозиторий предназначен только для распространения готовых релизов MAX Publisher AI и публичных метаданных обновления.

## Канал обновлений

- GitHub Releases: https://github.com/oraleeashe016-spec/MAX-Publisher-AI-Releases/releases
- Метаданные последней версии: https://github.com/oraleeashe016-spec/MAX-Publisher-AI-Releases/releases/latest
- Исходный код проекта находится в отдельном приватном репозитории и здесь не публикуется.

## Состав релиза

Каждая опубликованная версия должна включать:
- установщик Windows и/или ZIP-сборку;
- release notes с номером версии и перечнем изменений;
- SHA-256 контрольные суммы всех файлов;
- подписанный манифест патча Ed25519, когда доступно совместимое обновление.

## Безопасность

- Никогда не публиковать исходный код, файлы `.env`, API-токены, персональные данные или приватные ключи.
- Закрытый ключ Ed25519 хранить только в защищённом хранилище издателя / GitHub Actions Secrets приватного репозитория.
- Публичный ключ закрепляется в приложении и используется только для проверки подписи.
- Клиент должен отклонять обновления с отсутствующей или неверной подписью.
- Не публиковать `latest.json` со ссылкой на сборку, пока соответствующие файлы не загружены в GitHub Release и не проверены.

## Статус

Канал создан. Автоматическая публикация и клиентская проверка обновлений будут включены после настройки ключа подписи, release workflow и интеграции updater с интерфейсом приложения.
